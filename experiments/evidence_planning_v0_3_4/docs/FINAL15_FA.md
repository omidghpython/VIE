# ارزیابی نهایی۱۵سؤالی — نسخهٔ۰٫۲

**۱۵ سؤال واقعی و ثابت اکنون داخل بسته است:**۸ bridge و۷ comparison؛ جدا از۴۰ سؤال توسعه. مجموعهٔ نهایی فهرست خالی یا صرفاً ابزار بررسی هم‌پوشانی نیست.

## منشأ و انتخاب

داده از mirror عمومی۲۰۰ردیفی HotpotQA distractor validation روی GitHub دریافت شد. میزبان اصلی و Hugging Face از این محیط قابل دسترسی نبودند. نشانی ثابت commit و SHA256 فایل منبع در `data/final15_manifest.json` ثبت است؛ دریافت مستقیم از میزبان اصلی یا تطبیق بایت‌به‌بایت کل فایل اصلی ادعا نمی‌شود.

انتخاب بر اساس مرتب‌سازی هش شناسه، salt ثابت و سهمیهٔ۸/۷ انجام شد. پاسخ و نتیجهٔ مدل در انتخاب دخالت نداشتند.۸۹ شناسه و۵۴۱ هش متن سؤال/زیرسؤال در آرشیوها و گزارش‌های در دسترس بررسی شد؛۵۴۱ به معنی۵۴۱ سؤال مستقل نیست.۱۹۹ رکورد منبع با سوابق بررسی‌شده هم‌پوشانی نداشتند؛ انتخاب۱۵ از آن‌ها انجام شد.

«دیده‌نشده» یعنی استفاده‌نشده در سوابق توسعهٔ قابل‌بررسیِ این پروژه؛ دربارهٔ پیش‌آموزش Qwen یا آزمایش‌های خارج از منابع موجود ادعایی نداریم. انتخاب۱۵ سؤال نمونهٔ کوچکی است؛ مخرج، شکست و عدم‌قطعیت را همراه نتیجه گزارش کنید.

متن سؤال‌ها و snapshotهای شواهد در `data/final15_questions.jsonl` است. پاسخ‌ها و supporting facts در `private/final15_labels.jsonl` و رکوردهای اصلی منتخب در `private/final15_original_records.json` هستند؛ این داده‌های مرجع وارد پیام مدل نمی‌شوند. برای هر سؤال پنج وضعیت کنترل‌شدهٔ شاهد داریم:۷۵ وضعیت از۱۵ سؤال مستقل. حذف شاهد مرجع خودکار به معنی ناکافی‌بودن شواهد نیست؛ برچسب تصمیم صحیح نیازمند داوری مستقل است.

## اجرا

۱. توسعه و تنظیم را با `run_development.bat` و همان۴۰ سؤال انجام دهید. از۱۵ سؤال برای انتخاب پرامپت، بودجه یا رفع خطای روش استفاده نکنید.

۲. پس از تثبیت تنظیمات، `run_final15.bat` را اجرا کنید. ابتدا هویت کد، تنظیمات، مدل و داده قفل می‌شود.

۳. برای هر سؤال، تابع اصلی و بدون تغییر `generate_plan` در max4 اجرا می‌شود: حداکثر۲ تلاش ساختاری، ورودی۸۵۰۰ و خروجی۳۰۷۲توکن. داور معنایی و تعمیر معنایی اجرا نمی‌شوند. فقط سؤال اصلی به مولد داده می‌شود؛ پاسخ مرجع و شواهد وارد ساخت درخت نمی‌شوند.

۴. درخت ذخیره و برای هر دو حالت و تمام وضعیت‌های شاهد ثابت می‌ماند. سؤال ناموفق حذف یا جایگزین نمی‌شود و در شمارش۱۵ باقی می‌ماند.

۵. روی۷۵ وضعیت، دو حالت structured/flat اجرا می‌شوند؛ هر تصمیم یک فراخوانی با سقف ورودی۸۵۰۰ و خروجی۲۰۴۸توکن دارد. هزینهٔ تولید و تصمیم جدا ثبت می‌شوند.

۶. با `export_final15_results.bat` فایل `final15_results.zip` ساخته می‌شود؛ شامل درخت‌ها، تلاش‌های تولید، پاسخ‌های خام، هزینه و گزارش فارسی. فایل نتیجهٔ قبلی بازنویسی نمی‌شود.

۷. با `export_final15_review.bat` برگهٔ داوری بدون نام حالت ساخته می‌شود. فقط review_packets را به داور بدهید و نگاشت خصوصی را نزد مجری نگه دارید. پس از داوری، score و report-final15 را اجرا کنید.

```text
python run.py verify-final15
python run.py freeze-final15 --output results/final15_v1
python run.py run-final15 --output results/final15_v1
python run.py export-review --results results/final15_v1/decisions --output review/final15_v1
python run.py score --results results/final15_v1/decisions --reviews review/final15_v1/review_packets.jsonl --mapping review/final15_v1/private_mapping.json
python run.py report-final15 --results results/final15_v1
python run.py bundle-final15 --results results/final15_v1 --output final15_results.zip
```

تنظیمات پیش‌فرض در `configs/final15.json` است. تغییر لازم بر اساس نتایج توسعه را پیش از قفل نهایی انجام دهید. پس از شروع، تغییر کد/تنظیمات/داده یا استفاده از همین مجموعه در پوشهٔ نتیجهٔ تازه رد می‌شود. `data/final15_usage.json` ثبت استفادهٔ محلی را نگه می‌دارد. کپی پاک یک بسته از نظر علمی سؤالِ قبلاً دیده‌شده را دوباره دیده‌نشده نمی‌کند؛ سوابق استفاده باید بین نسخه‌ها حفظ شوند.

## ادامه و هزینه

اجرای دوباره با همان تنظیمات و پوشه از رکوردهای ذخیره‌شده ادامه می‌دهد. اگر پاسخ تولید ذخیره شده ولی ذخیرهٔ درخت قطع شده باشد، همان پاسخ خام در اعتبارسنج مبنا بازپخش می‌شود، بدون فراخوانی تازه. اگر مصرف فراخوانی قطع‌شده نامعلوم باشد، خودکار تکرار نمی‌شود.

سقف نظری کل۳۰ فراخوانی تولید و۱۵۰ تصمیم، مجموع۱۸۰ است. تعداد واقعی ممکن است با شکست یا رد ورودی کمتر شود. هزینهٔ شکست و خروجی ناقص حذف نمی‌شود. هزینهٔ تولید مشترک در کل اجرای واقعی فقط یک بار حساب می‌شود، نه به تعداد وضعیت‌ها و حالت‌ها. برای مقایسهٔ هزینهٔ مستقل هر حالت می‌توان همان هزینهٔ تولید مشترک را به هزینهٔ تصمیم آن حالت اضافه کرد؛ این جمع تحلیلی با کل مصرف واقعی متفاوت است.

## دامنهٔ نتیجه

این مسیر **ارزیابی نهایی آزمایش کنترل‌شدهٔ تصمیم‌گیری یک‌مرحله‌ای** است. query پیشنهادی هنوز به بازیاب فرستاده نمی‌شود؛ Answer Accuracy کامل RAG و مقایسهٔ کامل سه مسیر در دامنهٔ این runner نیستند. اگر نتایج این۱۵ سؤال برای اصلاح روش استفاده شود، این مجموعه دیگر آزمون نهاییِ دیده‌نشدهٔ نسخهٔ اصلاح‌شده نیست.

هیچ مدل زبانی در محیط ساخت روی۱۵ سؤال منتخب اجرا نشده است. آزمون‌های چرخهٔ اجرا از سؤال‌های کاملاً مصنوعی استفاده می‌کنند؛ روی۱۵ سؤال واقعی فقط تعداد، هویت، جداسازی و ساختار داده بررسی شده است. نتیجهٔ زنده هنوز انجام‌نشده است.
